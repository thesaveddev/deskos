ReyDesk — Comprehensive QA & UAT Test Script

End-to-end manual test guide covering every product surface · for go-live sign-off

Build
master @ latest deployed SHA
Scope
Full product — every feature, every role
Automated
npm test (API · 472+ tests) + npx playwright test (E2E · 68+ tests)
Priority key
P0 launch blocker · P1 must pass · P2 should pass
Before you start: Open the app in an incognito window. Have ready: (1) a Windows PC with the helper agent installed, (2) a Mac or tablet for the portal, (3) two people — a technician and a requester, (4) a Stripe/Paystack test mode account, (5) an S3-compatible bucket or local storage configured. Record failures with console (F12), the build hash, and the timestamp.
